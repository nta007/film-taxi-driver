# taxi-driver-gold

Repo phát triển truyện / kịch bản về:
- cựu tài xế vận chuyển ngầm
- con gái ông trùm xã hội đen
- hành trình TP.HCM -> Đà Nẵng
- bí mật kho vàng chiến tranh thất lạc

## File chính
- `STORY.md`: bản tóm tắt cốt truyện và các chi tiết đã chốt
- `CHARACTERS.md`: hồ sơ nhân vật và mạng quan hệ
- `CHAPTER_01/`: thư mục chứa toàn bộ các bản nháp và biến thể của Chương 1

## Quy ước cấu trúc
- Mỗi chương có thư mục riêng, ví dụ: `CHAPTER_01/`, `CHAPTER_02/`, ...
- Mọi bản nháp, biến thể và bản chốt của từng chương sẽ nằm trong thư mục chương tương ứng

## Hướng phát triển
- hoàn thiện hồ sơ nhân vật
- cấu trúc 3 hồi
- phát triển các chương theo cấu trúc thư mục riêng
